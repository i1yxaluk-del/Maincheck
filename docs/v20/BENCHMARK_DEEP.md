# Углублённый контрольный корпус v20

`benchmark-current.sh` теперь запускает 40 воспроизводимых проверок официально-делового русского текста:

- 30 положительных случаев, в каждом строго от 1 до 3 ошибок;
- 10 adversarial clean controls для измерения ложных срабатываний;
- длинные предложения, переносы строк, вложенные кавычки, Н(М)ЦК, номера, суммы, перечни и скобочные конструкции;
- точное сравнение всего исправленного текста с эталоном, а не только поиск одного ожидаемого фрагмента;
- отдельные показатели сохранения разделителей, переносов, корректного текста и качества объяснений.

Корпус создаётся детерминированно из `scripts/v20/build_deep_corpus.py`. Сценарий пересоздаёт файл перед каждым запуском, поэтому устаревший локальный JSONL не может скрыть изменения тестов.

Запуск:

```bash
sudo bash scripts/v20/benchmark-current.sh
```

Результат сохраняется как `results/deep-40-<timestamp>.json`. Каждая строка отчёта содержит исходный текст, точный эталон, фактический результат, количество ожидаемых ошибок, полученные объяснения и причину провала.

Первый clean control воспроизводит случай с Н(М)ЦК и `(оказанию услуг)`. Он должен остаться неизменным: нельзя добавлять скобку, менять Н(М)ЦК или частично принимать сомнительный пакет запятых.
